# Cleaner

See what's using your Mac's memory, uninstall apps you no longer use, control what opens at login, and clear out caches.

Requires macOS 26 or later.

## Install

Open Terminal and run:

```sh
curl -fsSL https://github.com/Zayan-Noor/cleaner-releases/releases/latest/download/install.sh | sh
```

Run the same command again to update.

Prefer a download? Get the DMG from [Releases](https://github.com/Zayan-Noor/cleaner-releases/releases/latest). It isn't notarized yet, so the first time you open it macOS will block it: go to **System Settings → Privacy & Security** and click **Open Anyway**.
